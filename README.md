## 🚀 Featured Projects

### 🛒 Thornview Grocery – Full-Stack Grocery eCommerce Platform

**Tech**:
Frontend – React (Vite), React Router DOM, Tailwind CSS, Leaflet, Lottie-react, React Icons
Backend – Node.js, Express.js, MongoDB, Socket.IO, CORS, cookie-parser, HTTP hardening, bcrypt
Auth, AI & Payments – Firebase Auth, JWT, Stripe, Gemini API, Axios, ImgBB, react-toastify

Inspired by the shopping experiences of major Canadian grocery platforms like Walmart.ca, providing a modern, scalable eCommerce solution for supermarkets and retail startups.

Role-based dashboards with separate access and protected routes for Admin, Manager, Customer, and Marketer roles with permission-based actions.

Real-time live support chat system engineered with Socket.IO to enable instantaneous communication between customers and administrators.

AI-powered assistant integration utilizing the Gemini API to dynamically generate quick replies and resolve user queries efficiently.

Smart location flow utilizing browser geolocation tracking, Leaflet maps, and reverse geocoding for automated address auto-fill capabilities.

Production-ready commerce features including secure authentication, Stripe payment processing gateways, and structured product, order, and user management.

🔗 **Live**: https://thomview-grocery.web.app/

💻 **Client Code**: https://github.com/masudrana430/Thornview-Grocery-client

### 🩸 BloodCare – Blood Donation Management & Funding Platform

**Tech**:
Frontend – React 18 (Vite), React Router DOM, Tailwind CSS, daisyUI, Lottie-react, React Icons, Axios (custom useAxiosSecure)
Backend – Node.js, Express.js, MongoDB
Auth & Payments – Firebase Authentication, JWT-protected APIs, ImgBB (avatar upload), Stripe (@stripe/react-stripe-js, @stripe/stripe-js), react-toastify

Public users can explore the landing page and view all pending blood donation requests with a clean, responsive UI and theme toggle.

Donors can create, edit, and delete their own donation requests, and track request status: pending, inprogress, done, canceled.

Role-based dashboards for Donor / Volunteer / Admin with dynamic overview cards (total users, total funding, total requests).

Admins can manage users (block/unblock, role changes) and admins/volunteers can manage all requests and update statuses.

Secure funding module using Stripe Card Payments, plus a full funding history (amount + date) for transparency.

Profile system includes dashboard profile data (blood group, district, upazila) and a public My Profile page to update Firebase name/photo.

🔗 **Live**: https://give-a-life.netlify.app/

💻 **Client Code**: https://github.com/masudrana430/GIVE_A_LIFE_clint

🖥️ **Server Code**: https://github.com/masudrana430/GIVE_A_LIFE_server

🚚 myDelivery – Full-Stack Parcel Delivery Platform
Tech:
Frontend – React, React Router, Tailwind CSS, Leaflet, Swiper, Framer Motion, Lucide React
Backend – Node.js, Express.js, MongoDB
Auth & Payments – Firebase Auth, Stripe, Axios

A full-stack parcel delivery application designed to optimize and simplify the end-to-end booking, tracking, and operational logistics lifecycle.

Role-based dashboards featuring secure, separate access control pipelines and custom workflows tailored for Admin, Rider, and User personas.

Dynamic parcel booking architecture built with complete form validation for diverse categories (Document vs. Non-Document), automatic costing parameters, and automated unique tracking ID generation.

Interactive coverage map integration powered by Leaflet to enable dynamic regional center distribution lookups and seamless real-time district search filters.

Data-driven admin command center aggregating critical business performance metrics into interactive charts for tracking live workflows, rider approvals, and strict payment history logs.
